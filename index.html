How to use this console

Press Begin descent to start the dive. Hold position freezes depth for closer sensor inspection. Ascend reverses the dive. Reset to surface returns the lander to 0 m.

Simulated telemetry for exhibit purposes — figures follow real pressure and temperature curves for the Mariana Trench.

# Deep Sea Trench Lander (Mariana Trench Submersible Hull Monitor)
This project is an interactive museum kiosk that simulates a submersible traveling deep into the Mariana Trench. It shows how the submarine and its hull respond as it moves from the ocean surface down to Challenger Deep (10,935 m). 

## Main Features:
Overview: Shows live depth, pressure, temperature, oxygen, battery, and hull stress.
Sonar: Displays a rotating sonar screen with simulated underwater objects.
Analytics: Shows live graphs for pressure and hull stress during the dive.
Mission Control: Provides dive controls, system messages, and important depth milestones.
Accessibility: Includes high contrast mode, text-size controls, keyboard support, and reduced-motion support.

## Controls:
Begin Descent: Starts the submarine's descent.
Hold Position: Stops the submarine at its current depth.
Ascend: Moves the submarine back toward the surface.
Reset to Surface: Returns everything to the starting point.

# Deep Sea Trench Lander
Mariana Trench Submersible Hull Monitor — interactive museum kiosk prototype.

## Technologies
- HTML5
- CSS3
- JavaScript
- SVG
- Canvas API

## Structure
- index.html — interface structure
- css/style.css — visual design, responsive layout and animations
- js/app.js — telemetry simulation, navigation, sonar, analytics, mission controls and accessibility behavior

## Technology:
The project is made using HTML, CSS, and JavaScript. Everything is contained in a single HTML file, so no framework, installation, or build process is required.

## How to Run:
Simply open the HTML file in a modern web browser. It can also be hosted on any static web server.

#### Note: The sensor readings are simulated for educational and exhibition purposes. They are designed to represent realistic deep-sea conditions but are not real sensor data.
